# Plán mailingů — установка (≈15 минут)

Приложение: неделя с фирмами и продуктами, календарь сделанного, название и фото подтягиваются по ссылке. Данные хранятся в Supabase, сайт и серверные функции на Vercel. Оба сервиса бесплатные.

## 1. Supabase (база + фото)

1. Зайди на https://supabase.com → **Start your project** → войди через GitHub.
2. **New project**: имя `plan-mailingu`, придумай пароль базы (запиши его), регион **Central EU (Frankfurt)**. Подожди 1–2 минуты.
3. Слева **SQL Editor** → **New query** → вставь всё содержимое файла `supabase.sql` → **Run**. Должно появиться «Success».
4. Возьми два значения:
   - **Project URL**: *Project Settings → Data API* (вида `https://abcd1234.supabase.co`).
   - **Secret key**: *Project Settings → API Keys* → раздел **Secret keys** → скопируй ключ `sb_secret_…`. Если там только старые ключи, бери **service_role** (длинный, начинается с `eyJ…`).

⚠️ Secret key никому не показывай и не вставляй в код. Он вставляется только в настройки Vercel.

## 2. Vercel (сайт)

Нужен Node.js на компе (проверка: `node -v`).

```bash
cd plan-mailingu
npx vercel
```
- Войди (через GitHub), на все вопросы жми Enter (имя проекта `plan-mailingu`).

Потом в браузере: https://vercel.com → проект **plan-mailingu** → **Settings → Environment Variables**, добавь:

| Name | Value |
|---|---|
| `SUPABASE_URL` | Project URL из шага 1 |
| `SUPABASE_SERVICE_KEY` | Secret key из шага 1 |
| `APP_PIN` | *(по желанию)* например `2468`, тогда без PIN никто не войдёт |

И задеплой в продакшен:
```bash
npx vercel --prod
```
Ссылка вида `https://plan-mailingu.vercel.app` — это и есть приложение. Её отправляешь начальнику.

> Без `APP_PIN` редактировать может любой, у кого есть ссылка. С PIN приложение один раз спросит код, а потом запомнит его на устройстве.

## 3. Установка на телефон

- **iPhone (Safari):** открыть ссылку → кнопка «Поделиться» → **На экран «Домой»**.
- **Android (Chrome):** открыть ссылку → ⋮ → **Установить приложение** / «Добавить на главный экран».

Появится иконка «Mailingy», приложение открывается на весь экран, без адресной строки.

## Как пользоваться

- **+ Přidat firmu / produkt** → вставить ссылку на продукт. Через секунду подставятся название и фото со страницы. Название можно переписать, фото заменить своим (вставить / перетащить / выбрать).
- Галочка **Hotovo?** → «Odesláno», день в календаре становится зелёным.
- Данные обновляются сами каждые 20 секунд и при открытии приложения.

## Если что-то не работает

- «Chybí SUPABASE_URL…» → не добавлены переменные в Vercel или после них не сделан `npx vercel --prod`.
- Ошибка при сохранении «db» → не запущен `supabase.sql` или скопирован не тот ключ (нужен secret / service_role, **не** publishable/anon).
- Фото не подтянулось → у некоторых сайтов нет `og:image` или они блокируют запросы. Тогда просто вставь фото вручную.
